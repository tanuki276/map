# Fablewind — 風の国の旅人

童話の挿絵を歩き回るような、オリジナルの Android 2.5D オープンワールド探索ゲームです。映画のキャラクターや既存の作品素材は使用していません。

## APK ダウンロード

**[Android APK をダウンロード](https://github.com/tanuki276/map/raw/refs/heads/main/apk/Fablewind-debug.apk)**

GitHub Actions の [Build Android APK](https://github.com/tanuki276/map/actions) からも取得できます。署名された debug APK（開発・テスト用）です。Android 7.0 以上に対応します。インストール時に端末側で不明なアプリの許可が必要な場合があります。

## 遊び方

- **左下のジョイスティック:** 斜め方向を含めて自由に歩く
- **右下の「駆ける / RUN」:** 押している間はダッシュ。ジョイスティックと同時に操作できます
- **ワープ / 右上の地図:** 7つの旅の門から行き先を選び、「この門へワープ」で移動。門は最初からすべて使えます
- **地図のピン / 行き先一覧:** タップで目的地を選択。右上の × で地図を閉じる
- **右側の + / −:** ズーム調整
- **自動セーブ:** 座標、ズーム、世界内時刻を端末に保存。起動すると前回の位置から再開

## 世界

| 要素 | 内容 |
| --- | --- |
| 広さ | シード固定のストリーミング生成・実質無限の座標空間 |
| 地形 | 草原、深い森、紅葉の森、黄金の麦畑、高地、雪山、川、霧の湿原 |
| 建築 | 街道沿いの村、露店、井戸、宿屋、城、風車、灯台、遺跡、願いの大樹 |
| 景観 | 連続した起伏、陰影のある樹冠と石壁、麦の穂、水面の波紋、ランタン、霧、舞う葉、夜の蛍 |
| 操作 | タッチジョイスティック、ダッシュ、ズーム、地図、7か所へのワープ |
| 動作 | オフライン、外部 API / アカウント / ネット接続不要 |

スタート地点は **ひだまりの村 (X=0, Y=0)**。7つの地域を街道と旅の門で結び、移動時には暗転・到着表示・座標の即時保存を行います。元のセーブデータも引き継ぎます。

| 旅の門 | 到着座標 | 景色 |
| --- | --- | --- |
| ひだまりの村 | (0, 0) | 赤い屋根、ランタン、露店、井戸 |
| 風鳴りの古城 | (38, -36) | 大きな尖塔、石壁、薔薇色の花 |
| 黄金の風車丘 | (23, 30) | 揺れる麦畑と回転する風車 |
| 霧灯台 | (-34, 41) | 水鏡、葦、睡蓮、流れる霧 |
| 星降りの遺跡 | (68, 22) | 苔むす石柱と青い結晶 |
| 願いの森 | (-42, -34) | 巨大な古木、吊り灯り、光るきのこ |
| 琥珀の谷 | (-65, 5) | 紅葉、南瓜、宿屋、舞い落ちる葉 |

旅の門の足元は平らで、水や建物に埋まらないように生成します。地図では番号・地名・色を併記し、ミニマップにも門を表示します。画面解像度に合わせて世界の表示倍率を揃え、周囲の地形をフレーム内で再利用します。ワープ中と地図表示中は歩行を停止し、アプリを離れた際にはタッチ入力を解除します。

## ビジュアルの作り方

建物・樹木・地面・狐の旅人はすべて **Android Canvas で一から組み立てたオリジナルの図形モデル**です。隣接タイルで頂点の高さを共有する地形、素材ごとのグラデーション、建物の屋根・壁・影を組み合わせて、2D の軽さを保ちながら立体的な世界を表現しています。現時点では GLB ファイルは使用していません。

## Android アプリを自分でビルド

必要環境は JDK 17、Android SDK 35、Gradle 8.10.2。

```sh
sh scripts/check-world.sh
gradle assembleDebug
```

生成ファイル: `app/build/outputs/apk/debug/app-debug.apk`

`.github/workflows/build-apk.yml` が main ブランチへのソースコードの push 時に自動ビルドし、`apk/Fablewind-debug.apk` を更新します。

## 実装の範囲

現在は**探索できる初期プレイアブル版**です。GLB の本格的な 3D キャラクター、建物内部、NPC 会話、戦闘、クエスト、サウンドなどは今後の追加対象です。GitHub Actions はプルリクエストでも Android ビルドとワープ・地形の回帰チェックを実行します。端末ごとの実機操作やフレームレートはまだ検証していません。
