# Fablewind — 風の国の旅人 · 3D Survival

童話の中を旅して、素材を集め、火を起こし、料理し、自分の拠点を建てる Android 向けのオフライン3D探索ゲームです。**66種類のオリジナルGLBモデル**を OpenGL ES で読み込みます。地形・建物・植物・旅人・生き物は3D、Canvasは操作画面だけに使います。

## インストールと現在の版

- 開発中の3D版: [PR #1](https://github.com/tanuki276/map/pull/1) の最新チェック、または [Build Android APK](https://github.com/tanuki276/map/actions) の最新成功実行から **Fablewind-Android-APK** を取得し、ZIP内のAPKをインストールしてください。
- [main に公開済みのAPK](https://github.com/tanuki276/map/raw/refs/heads/main/apk/Fablewind-debug.apk) は、マージされるまで以前の版です。
- Android 7.0以上 / OpenGL ES 2.0対応端末。署名された開発用debug APKです。

## 遊び方

| 操作 | 内容 |
|---|---|
| 左スティック | 歩く。『走る』と同時に押すと疾走 |
| 右側の空きスペースをドラッグ | カメラを回す / 上下の角度を調整 |
| 右の ＋ / − | カメラの距離を調整 |
| 攻撃 | 近くの魔物を攻撃。剣を製作すると攻撃力と距離が上がる |
| 盾を構える | 盾を製作すると防御を切り替えられる。防御時は持久力を消費 |
| 調べる / 採取 / 入る | 近くの対象に応じて採取、入室、着火、料理、水くみ、砲撃など |
| 製作 | 建築、道具・精錬、料理の3分類。レシピと所持数を確認 |
| 持ち物 | 食材、素材、装備、弾薬を確認。剣・盾・バケツは自動で使用可能になる |
| 地図 | 7つの旅の門から行き先を選んでワープ |
| 食べる / 飲む | 体力・満腹・渇きを回復 |

メニュー中は世界が停止します。アプリを離れると入力を解除して保存します。座標、時間、体調、持ち物、建築、採取済みの場所、宝箱、旅の進行を保存し、ワープ到着時にも即時保存します。旧版の座標・時刻は初回起動時に引き継ぎます。

## 最初のサバイバル

1. 村の木や岩、草花を採取して、木材・石・繊維・鉄鉱石・食材を集める。火打ち石1つと木の実4つを持って開始します。
2. **焚き火と作業台**を設置。焚き火は木材1つと火打ち石で着火し、120秒間使えます。火打ち石は消費しません。
3. **霧灯台の湿原**へワープ。葦から粘土と繊維を採取し、石と粘土で**炉**を建てる。
4. 炉の近くで鉄鉱石と木材を**鉄の延べ棒**に精錬。作業台でバケツ・剣・盾・砲弾を作る。
5. 井戸か水辺で水をくむ。小麦・きのこ・薬草・魚と組み合わせ、着火した焚き火や屋内のかまどで料理する。
6. 家、砲台、灯り、繰り返し収穫できる麦畑を建てる。設置を確定するまで材料は消費されません。

## 夜と寄り道

- 夜、村の外に茨の魔物・ウィスプ・石のゴーレムが現れ、接近して攻撃します。昼になると去ります。
- 村の中心、灯り、火のついた焚き火の周囲は安全地帯。剣と盾、砲台を使って戦えます。
- 砲台は砲弾を1つ消費して周辺の魔物を攻撃します。射撃・建築・料理はゲーム内の表現です。
- 宝箱には金貨・鉄・星のかけら。旅商人は金貨を素材・食料と交換してくれます。
- 七地域を巡り、星のかけら3つを願いの森の祭壇へ届けると報酬を得ます。
- 麦畑は約100秒で育ち、収穫後に再成長。野外の採取資源も時間で再生します。
- 体力が尽きると村の門に戻ります。持ち物と建築は失いません。

## GLBとソース

`app/src/main/assets/models/` にGLBと三角形数・寸法・部品数のマニフェスト、`art/fablewind-assets.blend` に編集可能なBlender原本を収録しています。瓦、窓枠、鎧戸、扉の板、根、帽子の羽根、道具などを実際のメッシュとして作っています。旅人の手足と尻尾は名前付きの部品として動かします。

追加の川仕事GLB12種: 板橋、渡し舟、水位計、水門、水車、桟橋、道標、荷車、魚干し台、天幕、測量小屋、道程標。6種を村・街道・湿原の景観に配置しています。舟の操縦、水門の修理、水車の稼働はまだ実装していません。[追加素材の一覧と寸法](art/RIVERWORKS.md) / [GLB読戻しプレビュー](art/previews/riverworks-sheet.jpg)。

生成元: `art/create_assets.py` / `art/river_assets.py` / `tools/make_atlas.py`。他作品のモデルやテクスチャは使用していません。[世界観の調査・地域設計・描画の範囲](art/DESIGN.md) も参照してください。

```sh
python tools/make_atlas.py  # Python + numpy + Pillow
blender -b -t 2 --python art/create_assets.py
```

## ビルドと検証

JDK17 / Android SDK35 / Gradle8.10.2。サーバー・APIキー・ネット接続はゲーム動作に不要です。

```sh
sh scripts/check-world.sh
gradle assembleDebug assembleDebugAndroidTest
```

CIではワープ、採取、製作の原子性、入退室、水くみ、料理、戦闘、夜の出現、セーブ復元とGLBデコーダーを確認します。さらにAndroidエミュレーターの実際のEGL画面で66モデル・7地域・屋内・夜・製作画面・地図を確認し、**Fablewind-3D-Android-QA** に画像を保存します。

端末ごとの実機性能は未検証です。描画はオリジナルの軽量3D実装で、AAA作品との画質同等性、物理破壊、自由な地形掘削、建築エディター、豊富な会話・ストーリーは今回の実装範囲に含みません。
